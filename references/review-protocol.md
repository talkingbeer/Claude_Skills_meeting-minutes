# 독립 검수 프로토콜

작성 컨텍스트와 분리된 검수자가 노트 문장과 전사본 발화를 1:1 대조한다.

## 검수 입력

- 검수 대상: `final.md` (마크다운 원본)
- 1차 원천: 마스킹된 전사본
- 교차 원천: 이전 회차 노트(있을 경우)
- 방식: 작성자 설명 없이 노트 문장과 전사본 발화(화자 라벨 포함)를 1:1 대조. 인터뷰어(HQ)가 되받은 문장은 2차 근거로만 인정

## 10항목 체크리스트

| 항목 | ID | 내용 | CRITICAL 조건 |
|---|---|---|---|
| 수치 전수 대조 | A | 원천에 없는 숫자 0건. 모든 수치, 기간, 인원을 전사본에서 확인 | 원천 없는 수치 1건+ |
| 방향 반전 | B | 원천과 반대 의미 0건 | 반전 1건+ |
| 화자 귀속 | C | 인터뷰어 발화를 인터뷰이 진술로 옮기지 않았는가. Q→A 확인, 주어 채우기 검증 | - |
| 확신도 태그 | D | 본문과 표의 태그 정합, 혼합 문단은 문장 단위 분리 | - |
| STT 파손 경화 | E | 파손 구간을 확신 서술하지 않았는가 | - |
| 교차 주장 | F | 타 인터뷰/회의 프레임을 이 노트의 "확인"으로 쓰지 않았는가 | - |
| 표 정합 | G | 논점/후속 표의 근거 절 번호, 용어 일관성 | 범주 오기(MAJOR) |
| PII | H | 실명, 이메일, 전화, 주민번호 0건 | PII 노출 1건+ |
| 요약 vs 전사본 | I | 요약이 뒤집은 대목을 전사본대로 썼는가 | - |
| 격상 서술 | J | 원천보다 강도를 올린 표현이 없는가 | - |

## 심각도

- **CRITICAL**: 수치 날조, 방향 반전, PII 노출
- **MAJOR**: 화자 귀속 오류, 범주 오기
- **MINOR**: 태그 불일치, 파손 경화, 격상 표현, 단서 탈락

## 판정 기준

- **APPROVE**: CRITICAL 0, MAJOR 0
- **APPROVE_WITH_MINOR**: CRITICAL 0, MAJOR 1~2, MINOR 제한 없음
- **REJECT**: CRITICAL 1+ 또는 MAJOR 3+

## 결함 표 형식

| ID | 심각도 | 항목 | 위치(final.md) | 노트 문장(그대로) | 원천 근거(전사본 인용, 화자 라벨) | 문제 | 권고 수정 문안 |

## 반영 규칙

- 결함은 `final.md`와 게이트 기준선(`01_input.txt`) 양쪽에 반영
- 반영 후 PII 스윕을 다시 돌린다
- 검수가 기각한 의심 건은 R-nn으로 번호를 매겨 기록(왜 기각했는지)
