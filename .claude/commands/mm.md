# 회의록 작성

$ARGUMENTS

아래 규칙에 따라 회의록을 작성한다. 이 파일이 위치한 프로젝트 루트에 `SKILL.md`, `assets/design.css`, `references/` 가 함께 있으면 참조한다.

## 1. 인테이크

아래 네 질문을 **항상** 묻는다. 사용자가 이미 정보를 줬어도 건너뛰지 않는다.

**A1. 주목적과 부목적**
- 주목적 단일 선택: DEC(의사결정 기록, 전파) / DIS(논의, 합의 추적) / RPT(현황, 실적 보고) / INS(기록, 인사이트 도출) / 1ON1(면담 기록) / INF(정보 전달, 공유)
- 부목적 복수 선택. "없음"은 단독 선택만 가능. 주목적과 같은 항목은 선택지에서 제외

**A2. 참석자 확인**
- 원천에서 화자를 자동 추출해 "원천 라벨 → 유*환 직책" 매핑표를 보여주고 확인/수정

**A3. 도출 목표**
- "이 회의록으로 도출하고 싶은 것은?" + 목적별 권장 선택안 제시
  - INS: "3YP 논점", "조직 진단", "신사업 가설" / DEC: "경영진 결정 전파", "실행 계획 공유"
  - RPT: "갭 원인 분석", "다음 회차 쟁점" / DIS: "합의/미합의 정리", "후속 논의 설계"
  - 1ON1: "면담 기록", "코칭 사항" / INF: "전달 사항 요약", "Q&A 기록"
- 자유 텍스트도 가능

**A4. 상세 수준**
- 요약 1p / 표준 / 상세 중 선택
- 기본값: INS 상세, DEC/RPT 표준, 1ON1/INF 요약, DIS 표준
- 사용자가 선택하면 기본값을 덮어쓴다

### 조건부 질문

| ID | 질문 | 조건 |

| B2 | 이전 회차 노트 폴더 | INS, 1ON1 시리즈 |

### 자동 처리

- 헤더: 원천에서 자동 추출
- 목차: 목적에 따라 자동 생성
- 즉시 고지: 법무, 노무 키워드 감지 시 자동 생성
- 주제 분류: 발언 흐름 기반 자동 추출
- 상세 수준: A4에서 확정된 값 사용

## 2. 문서 구조

### 구조 A: 진단노트형 (INS, 1ON1)

대상과 목적(card+범례) → 한눈 요약(.note, 산문 ①~⑥) → 핵심 진단(h3 15~18개, 산문, 문장 끝 [사실]/[본인 견해]/[전언]) → 지표, 조직 스냅샷(표) → 논점 P-n(표: 근거, 성격) → 후속 확인 F-n(표: 확인 경로) → 즉시 고지(조건부) → footer

INS/1ON1은 결정과 액션아이템을 만들지 않는다. 후속 확인 F-n만 사용.

### 구조 B: MPR형 (DEC, RPT, DIS)

참석과 배경(card) → 한눈 요약(.note) → 핵심 논의(h3, "A 지적 → B의 답" 양측 대비) → 결정 사항 → Action Items(신규 A-n + CARRY-OVER R-n) → 다음 회차 체크리스트 → footer

액션 표: # | Action Item | Owner | 기한 | 비고. 액션 문구는 "지표 X→Y" 지향.

## 3. 서술 규칙

- **산문 기본**, 불릿은 나열에만
- 인용 「」 인라인, 원문 그대로, 단서 보존
- 신뢰도 태그 문장 단위: 사실 / 본인 견해 / 전언 / 미확인
- 전사본이 1차 자료. 자동 요약은 누락 점검용. 어긋나면 전사본 우선
- STT 파손은 추정 금지, "(전사본 파손, ~로 추정)" 표기
- 인터뷰어 발화를 인터뷰이 진술로 귀속 금지
- 언어 격상 금지 (원천보다 강한 표현 사용 금지)

## 4. 마스킹

- 인물명: `유*환` 방식(가운데 글자 마스킹) + 직책 병기
- 3인칭 언급도 동일, 전 직장 일반화
- 실명 토큰 목록 미기록(건수만), 산출물 전체 PII 스윕

## 5. 디자인

IBM Carbon 무채색. 나눔고딕 단일(Google Fonts). 구분자 ", " / "-". 색 띠 없음. 프로젝트에 `assets/design.css`가 있으면 참조.

## 6. 윤문

humanize-korean 가능 시 light/보수/구조 동결. 불가 시 핵심 패턴(번역투, 진행형, 종결어미 반복) 수동 적용. 변경률 1% 미만 목표.

## 7. 독립 검수

문서당 1회. 10항목: 수치 대조, 방향 반전, 화자 귀속, 태그 정합, STT 파손, 교차 주장, 표 정합, PII, 요약 vs 전사본, 격상 서술. REJECT: CRITICAL 1+ 또는 MAJOR 3+.
